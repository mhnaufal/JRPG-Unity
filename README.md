# JERPG

A Simple Classic 2D JRPG Game made in Unity 6.

## Installation

1. Download and install Unity 6000.1.17f1
2. Clone this repository
3. Open up this project from Unity Hub
4. Play the game.

-- Dialogue with LancerNPC --

1. Hi peasant! Why does this village feel so... empty?
  A. Hello, traveler. Everyone fled. A mad shaman cursed every child in this village.
  B. I'm the only one left — keeping this place from rotting, and making sure that Shaman doesn't strike again.
2. What?! What a cruel, heartless man.
3. Where can I find him? I'll warn him to stop — one way or another.
  C. I wouldn't, if I were you. He dwells in the EAST, past the village edge. I've never dared go there myself... so I can't tell you exactly where he hides.

  D. I hope you can... I hope you don't die out there.
5. I won't.
6. I'm the greatest warrior this world has ever seen.
  E. ...Whatever you say.
